تسجيل الدخول

يُستخدم هذا الرمز فقط داخل متصفحك لحفظ التعديلات مباشرة في GitHub، ولا يُرسل أو يُخزَّن في أي مكان آخر. يجب أن يملك الرمز صلاحية Contents: Read and write على هذا المستودع فقط (fine-grained token) أو صلاحية repo الكاملة (classic token). لا تشارك هذا الرمز مع أي شخص، ولا تحفظ هذه الصفحة كرابط علني.

📊 إحصائيات المتجر

احصل على هذا الرمز من raheeq.goatcounter.com → Settings → API — أنشئ رمزًا جديدًا بصلاحية Read statistics فقط. يُحفظ هذا الرمز في متصفحك فقط (هذا الجهاز) حتى لا تحتاج لإدخاله كل مرة، وهو رمز قراءة فقط لا يمكنه تغيير أي شيء. نسيان الرمز المحفوظ
